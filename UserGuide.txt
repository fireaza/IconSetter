ICON SETTER - USER GUIDE
=========================

Give every folder in a tree its own icon, generated from an image file that lives inside it.


HOW TO USE
----------

1. Browse to (or drag-and-drop, or type) the root folder you want to customize.
   Scanning starts automatically once you pick a folder.

2. Put an image or icon file in each folder you want to customize, with a filename that
   STARTS WITH "icon" - for example icon.png, icon7.jpg, or "icon variant.png".
   Supported image formats: .png, .jpg, .jpeg, .bmp.
   A folder can also contain a ready-made icon*.ico file directly.

3. Review the results. Folders are shown as tiles with a preview of the icon they'll get.
   A folder with more than one icon candidate can be cycled through, or set to a random
   pick, using the small arrows under its tile.

4. Click Apply. In most cases the new icon appears in Explorer right away. If it doesn't:
   - Press F5 / click "Refresh Explorer" in Explorer.
   - A folder that already had a DIFFERENT icon before this Apply can take a little
     longer to update - this is a known Explorer quirk, not something the app can fully
     control. "Restart Explorer" (in the app) forces it, at the cost of closing every open
     Explorer window (it tries to reopen them afterward, though tab order and grouping
     aren't preserved).

5. If you change your mind, "Undo" on the results screen reverts exactly what the last
   Apply changed - back to whatever each folder had before, not just the default icon.


FILTERING AND BROWSING
-----------------------

- The chips under the address bar (With .ico / Has "icon" image / Has both / No .ico /
  Has multiple .ico) narrow the gallery down to one category at a time.
- "Show up-to-date folders" reveals folders that already match their target icon
  (hidden by default, since Apply won't touch them anyway).
- "Explorer style" browses folder-by-folder, the way Explorer itself does, instead of
  showing every matching folder in the tree flattened into one view.
- The search box filters by folder name.
- The clock-icon dropdown next to Browse remembers your last few scanned folders.


OPTIONS MENU
------------

- Convert non-.ico images automatically, and/or add missing icon sizes to existing
  .ico files that only have one resolution baked in.
- Always show up-to-date folders / folders with multiple .ico files, as a default.
- Set (or don't set) the .ico file itself to "hidden" after it's applied.
- Always skip images smaller than 256x256 during conversion, instead of asking.
- Exclude specific folders (and everything inside them) from being scanned at all.
- Clear scan data - deletes the app's saved cache of previous scan results. Doesn't
  touch your folders or icons, only makes the next scan start from scratch.


BUILDING A STANDALONE .EXE
----------------------------

Requires the .NET 8 SDK (not just the runtime): https://dotnet.microsoft.com/download/dotnet/8.0

Then either double-click build.bat, or run manually:
    dotnet publish -c Release

Output: bin\Release\net8.0-windows\win-x64\publish\IconSetter.exe - a single,
self-contained file. Copy it anywhere; it runs on a bare Windows 10/11 x64 machine with
nothing else installed.


LATEST UPDATE
--------------

Icons generated by converting a source image now include the full standard size set
(256/128/64/48/32/16px), matching what "Add missing sizes" already produced for existing
.ico files. Previously, freshly-converted icons were missing the 16px frame, so Explorer
had to scale one down from a larger frame for small-icon views - now every size is
rendered directly from the source image instead.


KNOWN LIMITS
------------

- Windows-only (uses WPF, WinForms' folder browser, and Shell32 APIs) - can't be built or
  run on macOS/Linux.
- Network drives and cloud-synced folders (OneDrive, etc.) can be slower to reflect
  changes, since Explorer's remote-file caching behaves a bit differently there.
- Instant icon updates aren't fully guaranteed for folders that already had a different
  icon before - see step 4 above.
